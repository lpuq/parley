Parley's icons, built into the app so they look the same on every desktop (a KDE or
other icon theme would otherwise replace them).

All but `parley-crown-symbolic.svg` are GNOME's Adwaita symbolic icons (adwaita-icon-theme,
by the GNOME Project, licensed LGPL-3.0-only or CC-BY-SA-3.0), renamed with a `parley-`
prefix. `parley-call-start-symbolic.svg` is turned a quarter turn clockwise. The crown was
drawn for Parley.
